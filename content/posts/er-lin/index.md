  今天上午大概九点半起床的，吃过早餐之后我就一直在忙着配置DeepSeek。
  我为什么要配置一个AI呢？
  一是我感觉AI已经到了勉强可以使用的阶段了，或者说，到了非专业人士只要注意一下也能尽情使用的阶段了，而我就是那个非专业人员。
  大概从十点开始，我主要在忙着研究DeepSeek里一个叫dsh-engram的长记忆插件，其简介如下：
    
  ![屏幕截图 2026-10-24 211520](<屏幕截图 2026-10-24 211520.png> )

  我可以通过这个插件给Deep seek设定一个人设，在任务处理的过程中它会自动收集我的各种做事习惯，个人偏好，并且记录的所有数据都是在本地存储，不会经过任何云处理。这也是我选择这个插件的原因，当然我心底里还是希望我的Deep seek不要和别人的一样，不然我直接用免费的网页版也是一样的效果。

   在我眼里Deep seek的作用大概就是一个助理，帮我做一些我懒得做的事情，比如Debug，写文档。
   
   我给的初始人设就是什么都没给，就让它自己看我喜欢什么样的。设定完之后我发现它给我的回复一股AI味，一下没忍住就拿Python官方主页来调教了一下Deep seek。内容如下：
   
      Python 是一种解释型、交互式、面向对象的 编程语言。

      它也可以作为需要可编程接口的应用程序的扩展语言。
      最后，Python 是可移植的：
      它在许多 Unix 变体（包括 Linux 和 macOS）以及 Windows 上运行。

  我为什么要用这个来调教它？因为这种语气我是最习惯的。至于最后它的关键词记成什么样，我让它自己写去了，原谅我实在懒得给它设定这些东西，要是我真有那么勤快，我为什么还要花钱配置Deep Seek呢？
  
  当然我用的是Flash，从早上十点一直调教到下午两点也只花了五块钱，整个上下文长度来到了1M。总体来说还是很便宜的，这期间我还让它接管了我类似知识库的东西，并且配置了QQ，微信的机器人，这样我要是再手机上有什么文件都能直接发给它。

  我还让它帮我找了一下我小时候读过的文章，全过程大概就花了五毛多一点。虽然最后确认了我当时看的是哪篇文章，但由于版权问题，我没能重新再看一遍，当然我在这个过程中找到了点别的
